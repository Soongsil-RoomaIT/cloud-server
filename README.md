# 백엔드 Core - Cloud Server 구축

| 영역      | 구현 사항  | 
| ---       | ---       | 
| Node.js API 서버  |	프론트엔드가 센서/기기 상태 조회 및 제어 요청|
| MQTT 연동	        | Raspberry Pi가 보내는 센서 데이터 수신, 제어 명령 전송| 
| 센서 데이터 처리   | 	온도/습도/CO₂/미세먼지/창문 상태 수신| 
| 기상청 API 연동    | 	외부 날씨 정보 조회|
| 자동화 판단        | 	센서 + 날씨 + 현관문 상태를 보고 동작 결정| 
| 원격 제어          | 	Web에서 받은 명령을 Raspberry Pi로 전달| 
| PostgreSQL        | 	센서값, 장치 상태, 제어 기록 저장| 
| ERD               |서버 측 데이터 구조 정의| 
| 제어 이력          | 	어떤 이유로 어떤 장치를 작동시켰는지 기록|
