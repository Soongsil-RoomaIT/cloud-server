# CO₂ 제외 첫 학습 결과

실행일: 2026-11-18. 출처: Van Rooyen et al. (2026), [UCL 7가구 데이터 V2](https://doi.org/10.17632/47gjkbm29h.2), CC BY 4.0. 원본에서 온도·습도·해당 방 창문 이벤트만 추출하고 과거 변화량과 5분 뒤 상태 변화 정답을 생성했습니다.

## 실행 범위

- 원본 7개 파일의 크기·SHA-256 검증 완료.
- 같은 방의 센서가 있는 35개 창문, 시점×창문 2,794,594행 추출.
- 연속 15분 이력·측정값·다음 상태가 있는 2,566,698행 사용.
- 학습 p1~p5: 1,799,234행 중 300,000행 사용(OPEN 2,150, CLOSE 2,158 전부 보존).
- 검증 p6: 382,487행. 모델·임계값 선택 전용.
- 최종 평가 p7: 384,977행. HOLD 384,454 / OPEN 258 / CLOSE 265.
- 입력 10개에 CO₂·eCO₂·TVOC·다른 가스·가스 파생값 없음. 모델 전용 자동 검증 14개 통과.

원본의 같은 시점을 여러 창문별로 사용한 행 수입니다. 독립된 집 표본 수는 **7개**입니다. 추출 단계의 원본 시간대 가정과 전처리 한계는 README에 기록했습니다.

## 비교

| 모델 | 검증 Macro-F1 | 최종 평가 Macro-F1 | 최종 평가 정확도 |
|---|---:|---:|---:|
| 항상 HOLD | 0.3331 | 0.3331 | 99.86% |
| 로지스틱 회귀 | 0.3313 | 0.3464 | 94.57% |
| 랜덤 포레스트 | **0.3384** | **0.3634** | 98.67% |

검증 Macro-F1으로 랜덤 포레스트를 선택했습니다. 임계값 0.8도 검증 집에서 선택했습니다. 최종 평가 결과를 보고 설정을 다시 조정하지 않았습니다.

선택 모델의 최종 평가:

| 동작 | 정밀도 | 재현율 | F1 | 실제 건수 |
|---|---:|---:|---:|---:|
| 유지 | 99.91% | 98.76% | 0.9933 | 384,454 |
| 열기 | **1.54%** | **5.04%** | 0.0236 | 258 |
| 닫기 | **3.91%** | **60.38%** | 0.0734 | 265 |

OPEN 추천 843개 중 실제 OPEN 13개, CLOSE 추천 4,097개 중 실제 CLOSE 160개입니다. 행동 예측 성능은 낮고 불필요한 동작 추천이 많습니다. 이 결과로 자동 제어에 사용할 수 있다고 판단하지 않습니다.

HOLD가 99.86%라서 아무것도 바꾸지 않는 기준 모델도 정확도가 높습니다. 따라서 98.67%라는 숫자만 발표하면 모델 성능을 오해하게 됩니다. 클래스별 정밀도·재현율 및 기준 모델과의 비교를 함께 제시해야 합니다. Macro-F1은 세 동작의 F1을 동일하게 평균한 점수입니다.

## 다음 실험

1. 실제 방에서 온도·습도·확인된 창문 상태, 사용자의 열기/닫기 선택과 이유를 수집합니다. 공기질 개선을 목표로 한다면 그 효과에 맞는 별도 평가 정답이 필요합니다.
2. 오염가스 센서의 모델명·단위를 확인하고, 실제 측정 가능한 항목과 호환되는 학습 데이터를 결정합니다. 가스값을 CO₂ 또는 다른 센서 단위로 임의 변환하지 않습니다.
3. 행동이 드문 5분 뒤 예측 외에 더 긴 예측 간격·사용자 승인형 추천·상태별 모델을 **학습/검증 집으로** 비교할 수 있습니다. 이미 결과를 본 p7은 이후 실험의 새로운 미사용 평가 집으로 간주하지 않습니다.
4. 실제 서버 연결 전 CO₂ 필수 입력 계약, 외부 날씨·공기질 정책, 수동 제어 우선권을 반영합니다.

재현 명령, 입력 명세와 데이터 출처는 [README.md](README.md), 상세 혼동행렬과 점수는 로컬 `model/artifacts/report.json`에 있습니다. `window_model.joblib`는 CPU에서 불러올 수 있는 약 10MB 파일입니다. 데이터·모델 파일은 Git에 포함하지 않고 실행 코드와 이 결과 요약을 공유합니다.
