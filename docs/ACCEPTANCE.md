# 구현 및 인수시험 상태

2026-10-21 로컬 데모 기준입니다. 실제 센서·모터·클라우드 네트워크 성능 시험은 수행하지 않았습니다.

| 요구사항 | 구현 | 검증 및 남은 항목 |
|---|---|---|
| FR-01 실시간 환경 | 5개 수치 REST/WS, 창문 상태, 버킷 평균 | 로컬 HTTP/WS·프론트 guard 통과. 실제 Edge 창문 스냅샷 필요 |
| FR-02 환경 변화 판단 | 2시간 전 실황·2시간 후 예보 조회, 규칙 기반 추천·승인/자동 | 모의 기상 응답 시험. API 키 실조회·실외 PM 소스·학습 모델은 미구현/미검증 |
| FR-03 현관문 10분 | 엣지 소유 600초 타이머, 클라우드 예약 시각 표시와 수동 CLOSE | 클라우드 예약 표시 및 중복 자동 닫기 방지 검증 |
| FR-04 사용자 조작 | 202/ACK, 중복 요청 차단, 수동 우선 시간 | 데모 ACK·실제 MQTT 브로커 시험 통과. 기존 Edge는 완료 ACK 미지원 |
| FR-05 동작 알림 | 저장된 웹 알림, WebSocket, 읽음 처리 | 로컬 검증. D의 FCM과 서비스 계정·사용자 연결 필요 |
| NFR-01 측정 후 5초 | 수신 즉시 브로드캐스트 | 로컬 통신만 검증. 센서 획득~실제 브라우저 전체 구간 실측 필요 |
| NFR-02 5초 내 구동 시작 | 즉시 publish, 데모 150ms ACK, 기본 5초 미확인 timeout | 실제 시작과 완전 도달 분리 시험 필요. 서버 timeout만으로 충족 주장 불가 |
| NFR-03 10초 내 로컬 전환 | Cloud 수신 timeout, 복구 리포트 | Edge 담당 모드 전환과 별개. broker 유지/cloud 중단 감지는 현 Edge 미지원 |

자동 시험: Node test 30개(HTTP/WS, Aedes MQTT 브로커, PostgreSQL PGlite SQL, 명령·중복·복구·자동화·기상 변환, JWT/공간 권한, 서비스계정 알림 모의시험). 별도 실제 frontend feat/control-page의 guard 검증 통과. 프론트 production build 통과, mock off. Docker 데몬은 실행되지 않아 Docker 서비스 전체 실행은 미실시입니다.

내장 브라우저에서는 이 실행 환경의 localhost로 접속하지 못해 화면 클릭 인수시험을 완료하지 못했습니다. HTTP/WS 서버 시험과 프론트 빌드/타입 계약 검증이 화면 실측을 대신한다고 간주하지 않습니다.

사용자 PC 터미널에서 npm start 후 점검할 항목:

1. 대시보드의 센서 5개 값, 목업 배지 없음, 기기 연결됨 표시
2. /history의 기간 전환 및 평균 차트
3. /control의 창문 열기 → 202 → 완료 표시 → 중복 동작 없음
4. /demo에서 연결 끊기·복구, 서버 heartbeat 유지, 복구 이벤트 한 번
5. /demo 자동화 활성화, 습도 75% 입력 → 추천 → 승인 → 창문 상태 변경
6. 서버 재시작 시 데모 데이터 초기화 표시 확인

실장비 도입 후에는 위 항목에 측정 시각·서버 수신 시각·웹 표시 시각·모터 시작/도달 시각을 함께 기록해야 합니다.
